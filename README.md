Lenguaje usado: Phyton

Instrucciones para ejecutar:
A través de varias herramientas es posible ejecutar cada punto. Si se instala Phyton en Windows o Linux para ejecutar los códigos en consola, se debe instalar de forma adicional la libreria de Numpy, la cual es necesaria para el simulador cuántico. También es posible ejecutarlos, instalando Visual Studio Code o Google Colab. Para facilitar la ejecución, se puede usar también GitHub Codespaces.
